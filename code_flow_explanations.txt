================================================================================

function/method, and HTTP REST API route across all 8 execution flows, followed

and PDF Export flows.

3. DATA INSIGHTS (EDA) & EXPORT PDF WORKFLOW TRACES
================================================================================

--------------------------------------------------------------------------------
A. DATA INSIGHTS (IN-MEMORY EXPLORATORY DATA ANALYSIS - EDA) FLOW
--------------------------------------------------------------------------------
Goal: Stream database table rows into Pandas, detect nulls/duplicates, infer semantic types, and compute statistical column profiles.

Step 1: User switches to [ Data Insights ] tab in navigation bar.
        - Frontend: static/index.html -> switchViewMode('datainsights')
        - Populates dropdowns via GET endpoints:
          * GET /api/data-insights/databases -> app.py get_eda_databases() -> DataInsightsService.list_databases()
          * GET /api/data-insights/schemas   -> app.py get_eda_schemas()   -> DataInsightsService.list_schemas()
          * GET /api/data-insights/tables    -> app.py get_eda_tables()    -> DataInsightsService.list_tables()

Step 2: User selects Table and Sample Size (e.g. 1000 rows), then clicks "Analyze Data".
        - Frontend: static/index.html -> runDataInsightsAnalysis()
        - Sends HTTP POST request to `/api/data-insights/profile` with payload.

Step 3: FastAPI endpoint delegates to DataInsightsService:
        - File   : app.py
        - Route  : POST /api/data-insights/profile
        - Method : async def profile_dataset(req: EDAProfileRequest)
        - Service: data_insights_service.profile_table(db_type, creds, db_name, schema, table_name, sample_size)

Step 4: EDA Pipeline Execution (datainsights/EDA/):
        1. Connect to DB  : DatabaseConnectorFactory.get_connector(...) in datainsights/EDA/connectors.py
        2. Load to Pandas : DataLoader.load_table_as_df(...) in datainsights/EDA/sources.py (SELECT * FROM table LIMIT size)
        3. Clean Nulls    : MissingValueNormalizer.normalize(df) in datainsights/EDA/semantics.py ('N/A', 'null' -> np.nan)
        4. Detect Semantics: SemanticSchemaRefiner.refine(df) in datainsights/EDA/semantics.py (Email, Currency, UUID, ID, Timestamp)
        5. Quality Checks : DataInconsistencyAnalyzer.analyze(df) & DuplicateRecordAnalyzer.analyze(df) in datainsights/EDA/quality.py
        6. Compute Stats  : DatasetProfiler.profile(df) in datainsights/EDA/profiling.py (mean, median, stddev, min, max, quantiles)
        7. Imputations    : ImputationRecommender.add_recommendations(df, profiles) in datainsights/EDA/imputation.py
        8. Report Dict    : EDAReportEntry.to_dict() in datainsights/EDA/reporting.py

Step 5: Frontend renders interactive EDA dashboard:
        - Frontend: static/index.html -> renderDataInsightsResults(data)
        - Renders Quality Scorecard (0-100), Missingness Distribution Chart, Semantic Types Donut Chart, Column Statistics Table, and Imputation Recommendations.


--------------------------------------------------------------------------------
B. PDF REPORT EXPORT FLOWS (OBSERVABILITY & DATA INSIGHTS)
--------------------------------------------------------------------------------
Goal: Convert observability metrics or EDA profiling data into styled Navy Blue ReportLab PDF documents.

[OPTION 1] Observability Dashboard PDF Export:
  1. User clicks "Export PDF Report" in navbar.
  2. Frontend: static/index.html -> exportObservabilityPdf() -> POST /api/export-pdf
  3. Backend : app.py -> @app.post("/api/export-pdf") -> async def export_pdf(req: PDFExportRequest)
  4. Builder : pdf_generator.py -> PDFReportGenerator(filepath).generate_report(report_data)
     - _build_header(canvas, doc)    -> Draws Navy Blue top banner (#1E3A8A) & logo.
     - add_key_value_table(...)      -> Draws executive KPI scorecards grid.
     - add_report_table(...)         -> Formats metric tables with alternating row shading.
     - NumberedCanvas.draw_page_decorations() -> Writes footer "Page X of Y" and execution timestamp.
     - doc.build(story, canvasmaker=NumberedCanvas) -> Compiles binary PDF document.
  5. Response: app.py returns FileResponse(pdf_path, media_type="application/pdf").
  6. Browser : Triggers automatic file download to user's computer.

[OPTION 2] Data Insights (EDA) PDF Export:
  1. User clicks "Export Data Insights PDF".
  2. Frontend: static/index.html -> exportDataInsightsPdf() -> POST /api/data-insights/export-pdf
  3. Backend : app.py -> @app.post("/api/data-insights/export-pdf") -> async def export_eda_pdf(req)
  4. Builder : pdf_generator.py -> PDFReportGenerator.generate_data_insights_report(profile_data) OR datainsights/EDA/reporting.py -> PDFStatisticsReportWriter.save(filepath, report_entry)
  5. Response: app.py returns FileResponse(pdf_path, media_type="application/pdf") for browser download.
