================================================================================
DATABASE METADATA EXPLORER — DEPLOYMENT & SETUP GUIDE
================================================================================
Supported Database Engines: MySQL, PostgreSQL, Oracle, Microsoft SQL Server
Updated: 2026-10-06


================================================================================
1. QUICK START (GET RUNNING IN 3 STEPS)
================================================================================

Step 1: Open PowerShell or Command Prompt in project root directory:
   cd path\to\database_metadata_explorer

Step 2: Create & activate virtual environment, then install dependencies:
   python -m venv venv
   .\venv\Scripts\Activate.ps1   # Windows PowerShell
   pip install -r requirements.txt

Step 3: Launch Web Application:
   python main.py

   Access the Web Dashboard in your browser: http://localhost:8000


================================================================================
2. PREREQUISITES & SYSTEM REQUIREMENTS
================================================================================

1. Python Version:
   - Python 3.9 or higher (Python 3.10 / 3.11 / 3.12 / 3.13 recommended).

2. Database Driver Dependencies & Native Client Drivers:
   - MySQL (Port 3306)      : Powered by `mysql-connector-python`.
   - PostgreSQL (Port 5432) : Powered by `psycopg2-binary`.
   - Oracle (Port 1521)     : Powered by `oracledb` (runs in default Thin Mode, no Instant Client required).
   - SQL Server (Port 1433) : Powered by `pyodbc` (Requires Microsoft ODBC Driver 17 or 18 for SQL Server).

3. Microsoft ODBC Driver for SQL Server Installation:
   - Windows : Download & install "Microsoft ODBC Driver 18 for SQL Server" from Microsoft website.
   - Linux (Ubuntu/Debian) :
       curl https://packages.microsoft.com/keys/microsoft.asc | sudo apt-key add -
       curl https://packages.microsoft.com/config/ubuntu/$(lsb_release -rs)/prod.list > /etc/apt/sources.list.d/mssql-release.list
       sudo apt-get update
       sudo ACCEPT_EULA=Y apt-get install -y msodbcsql18 unixodbc-dev
   - macOS :
       brew tap microsoft/mssql-release https://github.com/Microsoft/homebrew-mssql-release
       brew update
       ACCEPT_EULA=Y brew install msodbcsql18 mssql-tools18

================================================================================

STEP 1 — Clone / Extract Project Repository
-------------------------------------------
Copy the `database_metadata_explorer` directory to your target server or local machine.

5. DATABASE CONNECTION PARAMETERS & CREDENTIALS GUIDE
================================================================================

1. MySQL Connection:
   - Host             : Database server hostname or IP address (e.g., localhost, 127.0.0.1)
   - Port             : Default 3306
   - Username / Pass  : Valid MySQL user credentials

2. PostgreSQL Connection:
   - Host             : Server IP or hostname
   - Port             : Default 5432
   - Database / Schema: Optional. If left blank, automatically scans ALL databases across instance!

3. Oracle Database Connection:
   - Host             : Server IP or hostname
   - Port             : Default 1521
   - Service Name     : Oracle Service Name (e.g., ORCL, FREEPDB1, XE)
   - Schema           : Optional. Defaults to authenticated username schema if omitted.

4. Microsoft SQL Server Connection:
   - Host             : Server IP or hostname
   - Port             : Default 1433
   - Database / Schema: Optional. If left blank, scans all accessible user databases!

6. PRODUCTION DEPLOYMENT OPTIONS
================================================================================

OPTION A — Running as a Linux Systemd Service:
----------------------------------------------
1. Create service unit file `/etc/systemd/system/db-metadata-explorer.service`:

   [Unit]
   Description=Database Metadata Explorer Web Application
   After=network.target

   [Service]
   User=ubuntu
   WorkingDirectory=/home/ubuntu/database_metadata_explorer
   ExecStart=/home/ubuntu/database_metadata_explorer/venv/bin/uvicorn app:app --host 0.0.0.0 --port 8000 --workers 4
   Restart=always

   [Install]
   WantedBy=multi-user.target

2. Enable & start service:
   sudo systemctl daemon-reload
   sudo systemctl enable db-metadata-explorer
   sudo systemctl start db-metadata-explorer


OPTION B — Running with Nginx Reverse Proxy:
--------------------------------------------
Configure Nginx block to proxy incoming traffic on port 80/443 to uvicorn on 127.0.0.1:8000:

   server {
       listen 80;
       server_name db-observability.example.com;

       location / {
           proxy_pass http://127.0.0.1:8000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
       }
   }

7. TROUBLESHOOTING COMMON ISSUES
================================================================================

1. Error: "pyodbc.Error: ('08001', '[08001] [Microsoft][ODBC Driver 18 for SQL Server]...')"
   - Resolution: Ensure Microsoft ODBC Driver 18 is installed on your system.

2. Error: "Execution Policy Restriction on PowerShell"
   - Resolution: Run `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process` before activating venv.

3. Error: "Port 8000 is already in use"
   - Resolution: Specify a custom port when launching:
     uvicorn app:app --host 0.0.0.0 --port 8080

4. Error: "Connection timed out to Oracle / MySQL / Postgres / SQL Server"
   - Resolution: Verify firewall rules and target database configuration (e.g., `pg_hba.conf` for Postgres or `bind-address` for MySQL).
