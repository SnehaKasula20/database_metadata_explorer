================================================================================
DATABASE METADATA EXPLORER — DEPLOYMENT GUIDE
================================================================================
Supported Databases: MySQL, PostgreSQL, Oracle, and Microsoft SQL Server
Updated: 2026-09-24

================================================================================
QUICK START (3 SIMPLE STEPS)
================================================================================

1. Open PowerShell / Command Prompt in the project folder:
   cd path\to\database_metadata_explorer

2. Setup virtual environment & install requirements:
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   pip install -r requirements.txt

3. Start the application:
   python main.py

   Open your web browser at: http://localhost:8000

================================================================================
PREREQUISITES
================================================================================

1. Python 3.9 or higher (Python 3.10 / 3.11 / 3.12 / 3.13 recommended)
2. Network connectivity & reachable database ports:
   - MySQL      : Port 3306
   - PostgreSQL : Port 5432
   - Oracle     : Port 1521
   - SQL Server : Port 1433 (+ Microsoft ODBC Driver 18 for SQL Server)
3. Fonts (Optional for PDF Reports):
   - Windows includes Calibri font by default at C:\Windows\Fonts\calibri.ttf
   - Linux/macOS falls back to Helvetica automatically.

================================================================================
STEP-BY-STEP SETUP GUIDE
================================================================================

STEP 1 — Copy Project Folder
---------------------------------
Copy the `database_metadata_explorer` directory to the target machine.

STEP 2 — Open Terminal / PowerShell
---------------------------------
Windows PowerShell / CMD:
  cd path\to\database_metadata_explorer

Linux / macOS:
  cd path/to/database_metadata_explorer

STEP 3 — Create Virtual Environment
---------------------------------
python -m venv venv

STEP 4 — Activate Virtual Environment
---------------------------------
Windows (PowerShell):
  .\venv\Scripts\Activate.ps1

Windows (Command Prompt):
  venv\Scripts\activate.bat

Linux / macOS:
  source venv/bin/activate

STEP 5 — Install Dependencies
---------------------------------
To install dependencies for all supported databases:
  pip install -r requirements.txt

Individual database installation (if only using specific databases):
  - MySQL      : pip install mysql-connector-python reportlab fastapi uvicorn
  - PostgreSQL : pip install psycopg2-binary reportlab fastapi uvicorn
  - Oracle     : pip install oracledb reportlab fastapi uvicorn
  - SQL Server : pip install pyodbc reportlab fastapi uvicorn

STEP 6 — Launch Application
---------------------------------
Option A — Main Menu / Web Interface (Recommended):
  python main.py

Option B — Direct Web API Server:
  python app.py

Option C — Development Mode (with Hot Reloading):
  uvicorn app:app --reload

================================================================================
DATABASE CONNECTION DETAILS
================================================================================

1. MySQL
   - Default Port: 3306
   - Required Fields: Host, Port, Username, Password

2. PostgreSQL
   - Default Port: 5432
   - Required Fields: Host, Port, Username, Password, Database

3. Oracle Database
   - Default Port: 1521
   - Required Fields: Host, Port, Username, Password, Service Name
   - Note: Connects using standard Thin Mode (no Instant Client needed).

4. Microsoft SQL Server
   - Default Port: 1433
   - Required Fields: Host, Port, Username, Password, Database, Schema (default: dbo)
   - Note: Requires Microsoft ODBC Driver 18 for SQL Server installed on system.

================================================================================
PDF REPORT GENERATION
================================================================================

- Output Folder: reports\
- Format: Landscape Letter PDF with auto-wrapped tables and key database insights.
- PDFs auto-open upon generation on Windows.
