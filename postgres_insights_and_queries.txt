================================================================================
POSTGRESQL DATABASE INSIGHTS & SQL QUERIES REFERENCE (65 INSIGHTS)
================================================================================

IMPORTANT:
- Queries are intended for PostgreSQL and use PostgreSQL system catalogs / information_schema.
- Most database-object queries are scoped to the current database.
- Replace the schema filter only if you intentionally want system schemas included.
- PostgreSQL does not have direct equivalents for some Oracle concepts such as SGA/PGA,
  tablespaces in the Oracle sense, ASM, Data Guard, and UNDO tablespaces. For those,
  PostgreSQL-specific operational insights are provided instead.

COMMON USER-SCHEMA FILTER:
    n.nspname NOT IN ('pg_catalog','information_schema')
    AND n.nspname NOT LIKE 'pg_toast%'
    AND n.nspname NOT LIKE 'pg_temp_%'

INSIGHT #01: PostgreSQL version and environment
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_environment_info()
Headers     : PostgreSQL Version, Server Version, Database, Server Address, Port, Current User
Description : PostgreSQL server, database, connection and version information.

SQL Query:
SELECT
    version() AS postgres_version,
    current_setting('server_version') AS server_version,
    current_database() AS database_name,
    inet_server_addr() AS server_address,
    inet_server_port() AS port,
    current_user AS current_user;

INSIGHT #02: Database inventory
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_database_inventory()
Headers     : Database Name, Owner, Size (MB), Size (GB)
Description : Databases visible to the current PostgreSQL cluster with their sizes.

SQL Query:
SELECT
    d.datname AS database_name,
    pg_get_userbyid(d.datdba) AS owner,
    ROUND((sz.raw_bytes / 1024.0 / 1024)::numeric, 2) AS size_mb,
    ROUND((sz.raw_bytes / 1024.0 / 1024 / 1024)::numeric, 2) AS size_gb
FROM pg_database d
JOIN (
    SELECT oid, pg_database_size(oid) AS raw_bytes
    FROM pg_database
    WHERE datallowconn = true
      AND datistemplate = false
) sz ON d.oid = sz.oid
ORDER BY sz.raw_bytes DESC;

INSIGHT #03: Schema/table storage analysis
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_schema_table_storage_analysis()
Headers     : Schema, Table Name, Size (MB), Size (GB)
Description : Table storage analysis (including indexes and TOAST).

SQL Query:
SELECT
    n.nspname AS schema_name,
    c.relname AS table_name,
    ROUND((pg_total_relation_size(c.oid) / 1024.0 / 1024)::numeric, 2) AS size_mb,
    ROUND((pg_total_relation_size(c.oid) / 1024.0 / 1024 / 1024)::numeric, 2) AS size_gb
FROM pg_class c
JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE c.relkind IN ('r','p')
  AND n.nspname NOT IN ('pg_catalog','information_schema')
  AND n.nspname NOT LIKE 'pg_toast%'
ORDER BY pg_total_relation_size(c.oid) DESC;

INSIGHT #04: Total table vs index storage
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_total_table_vs_index_storage()
Headers     : Table Storage (MB), Index Storage (MB), Total Storage (MB), Table Storage (GB), Index Storage (GB), Total Storage (GB)
Description : Database-wide table heap, index and total relation storage.

SQL Query:
SELECT
    ROUND((COALESCE(SUM(pg_relation_size(c.oid)), 0) / 1024.0 / 1024)::numeric, 2) AS table_mb,
    ROUND((COALESCE(SUM(pg_indexes_size(c.oid)), 0) / 1024.0 / 1024)::numeric, 2) AS index_mb,
    ROUND((COALESCE(SUM(pg_total_relation_size(c.oid)), 0) / 1024.0 / 1024)::numeric, 2) AS total_mb,
    ROUND((COALESCE(SUM(pg_relation_size(c.oid)), 0) / 1024.0 / 1024 / 1024)::numeric, 2) AS table_gb,
    ROUND((COALESCE(SUM(pg_indexes_size(c.oid)), 0) / 1024.0 / 1024 / 1024)::numeric, 2) AS index_gb,
    ROUND((COALESCE(SUM(pg_total_relation_size(c.oid)), 0) / 1024.0 / 1024 / 1024)::numeric, 2) AS total_gb
FROM pg_class c
JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE c.relkind IN ('r','p')
  AND n.nspname NOT IN ('pg_catalog','information_schema')
  AND n.nspname NOT LIKE 'pg_toast%';


--------------------------------------------------------------------------------
INSIGHT #05: Top 100 tables
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_top_100_largest_relations()
Headers     : Database, Schema, Table Name, Relation Type, Row Count, Size (MB), Size (GB)
Description : Top 100 largest user tables/partitioned tables by row count.

SQL Query:
SELECT
    n.nspname AS schema_name,
    c.relname AS relation_name,
    CASE c.relkind
        WHEN 'r' THEN 'Table'
        WHEN 'p' THEN 'Partitioned Table'
        WHEN 'i' THEN 'Index'
        WHEN 'm' THEN 'Materialized View'
        WHEN 'v' THEN 'View'
        ELSE c.relkind::text
    END AS relation_type,
    GREATEST(c.reltuples::bigint, 0) AS row_count,
    ROUND((pg_total_relation_size(c.oid) / 1024.0 / 1024)::numeric, 2) AS size_mb,
    ROUND((pg_total_relation_size(c.oid) / 1024.0 / 1024 / 1024)::numeric, 2) AS size_gb
FROM pg_class c
JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE c.relkind IN ('r','p')
  AND n.nspname NOT IN ('pg_catalog','information_schema')
  AND n.nspname NOT LIKE 'pg_toast%'
ORDER BY GREATEST(c.reltuples::bigint, 0) DESC, pg_total_relation_size(c.oid) DESC
LIMIT 100;

INSIGHT #06: Tablespace usage
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_tablespace_usage()
Headers     : Tablespace Name, Owner, Location, Size (GB)
Description : PostgreSQL tablespaces and the size of objects stored in each.

SQL Query:
WITH relation_sizes AS (
    SELECT
        c.oid,
        c.reltablespace,
        pg_total_relation_size(c.oid) AS total_size
    FROM pg_class c
    JOIN pg_namespace n ON n.oid = c.relnamespace
    WHERE c.relkind IN ('r','p','m')
      AND n.nspname NOT IN ('pg_catalog','information_schema')
      AND n.nspname NOT LIKE 'pg_toast%'
)
SELECT
    t.spcname AS tablespace_name,
    pg_get_userbyid(t.spcowner) AS owner,
    COALESCE(NULLIF(pg_tablespace_location(t.oid), ''), current_setting('data_directory')) AS location,
    ROUND(COALESCE(SUM(rs.total_size), 0) / 1024.0 / 1024 / 1024, 2) AS size_gb
FROM pg_tablespace t
LEFT JOIN relation_sizes rs
  ON rs.reltablespace = t.oid
  OR (rs.reltablespace = 0 AND t.oid = (
      SELECT dattablespace
      FROM pg_database
      WHERE datname = current_database()
  ))
GROUP BY t.oid, t.spcname, t.spcowner
ORDER BY size_gb DESC;


--------------------------------------------------------------------------------
INSIGHT #07: Tablespace object storage
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_tablespace_object_storage()
Headers     : Tablespace Name, Object Count, Total Object Size (GB)
Description : Object storage assigned to each PostgreSQL tablespace, including objects
              that inherit the current database's default tablespace.

SQL Query:
WITH relation_sizes AS (
    SELECT
        c.oid,
        CASE
            WHEN c.reltablespace = 0 THEN d.dattablespace
            ELSE c.reltablespace
        END AS tablespace_oid
    FROM pg_class c
    JOIN pg_namespace n ON n.oid = c.relnamespace
    CROSS JOIN (
        SELECT dattablespace
        FROM pg_database
        WHERE datname = current_database()
    ) d
    WHERE c.relkind IN ('r','p','i','I','m')
      AND n.nspname NOT IN ('pg_catalog','information_schema')
      AND n.nspname NOT LIKE 'pg_toast%'
)
SELECT
    t.spcname AS tablespace_name,
    COUNT(rs.oid) AS object_count,
    ROUND(
        COALESCE(SUM(pg_total_relation_size(rs.oid)), 0)
        / 1024.0 / 1024 / 1024,
        2
    ) AS total_size_gb
FROM pg_tablespace t
LEFT JOIN relation_sizes rs
  ON rs.tablespace_oid = t.oid
GROUP BY t.oid, t.spcname
ORDER BY total_size_gb DESC;

INSIGHT #09: Master (Parent) tables
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_master_tables()
Headers     : Schema, Parent Table, Child FK Count, Referencing Child Tables
Description : Tables referenced by foreign-key constraints.

SQL Query:
SELECT
    parent_ns.nspname AS schema_name,
    parent.relname AS table_name,
    COUNT(*) AS child_fk_count,
    STRING_AGG(DISTINCT child_ns.nspname || '.' || child.relname, ', '
               ORDER BY child_ns.nspname || '.' || child.relname) AS child_tables
FROM pg_constraint con
JOIN pg_class parent ON parent.oid = con.confrelid
JOIN pg_namespace parent_ns ON parent_ns.oid = parent.relnamespace
JOIN pg_class child ON child.oid = con.conrelid
JOIN pg_namespace child_ns ON child_ns.oid = child.relnamespace
WHERE con.contype = 'f'
  AND parent_ns.nspname NOT IN ('pg_catalog','information_schema')
GROUP BY parent_ns.nspname, parent.relname
ORDER BY child_fk_count DESC, schema_name, table_name;

INSIGHT #20: Index columns
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_index_columns()
Headers     : Schema, Table Name, Index Name, Column Position, Column Name
Description : Columns and positions used by each index.

SQL Query:
SELECT
    n.nspname AS schema_name,
    t.relname AS table_name,
    i.relname AS index_name,
    k.n AS column_position,
    a.attname AS column_name
FROM pg_index ix
JOIN pg_class t ON t.oid = ix.indrelid
JOIN pg_class i ON i.oid = ix.indexrelid
JOIN pg_namespace n ON n.oid = t.relnamespace
CROSS JOIN LATERAL generate_subscripts(ix.indkey, 1) AS k(n)
JOIN pg_attribute a
  ON a.attrelid = t.oid
 AND a.attnum = ix.indkey[k.n]
WHERE n.nspname NOT IN ('pg_catalog','information_schema')
ORDER BY n.nspname, t.relname, i.relname, k.n;

INSIGHT #26: Duplicate/redundant index candidates
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_duplicate_index_candidates()
Headers     : Schema, Table Name, Index A, Index B, Definition
Description : Candidate duplicate indexes with the same normalized CREATE INDEX
              definition after removing the index name. Review uniqueness, predicates,
              expressions, included columns and workload before removing any index.

SQL Query:
WITH idx AS (
    SELECT
        n.nspname AS schema_name,
        t.relname AS table_name,
        i.relname AS index_name,
        regexp_replace(
            pg_get_indexdef(ix.indexrelid),
            '^CREATE (UNIQUE )?INDEX [^ ]+ ON ',
            'CREATE INDEX ON '
        ) AS normalized_definition
    FROM pg_index ix
    JOIN pg_class t ON t.oid = ix.indrelid
    JOIN pg_class i ON i.oid = ix.indexrelid
    JOIN pg_namespace n ON n.oid = t.relnamespace
    WHERE n.nspname NOT IN ('pg_catalog','information_schema')
      AND n.nspname NOT LIKE 'pg_toast%'
)
SELECT
    a.schema_name,
    a.table_name,
    a.index_name AS index_a,
    b.index_name AS index_b,
    a.normalized_definition AS definition
FROM idx a
JOIN idx b
  ON b.schema_name = a.schema_name
 AND b.table_name = a.table_name
 AND b.normalized_definition = a.normalized_definition
 AND b.index_name > a.index_name
ORDER BY a.schema_name, a.table_name, a.index_name, b.index_name;

INSIGHT #29: Stored procedures
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_stored_procedures()
Headers     : Schema, Procedure Name, Language, Owner, Definition
Description : Procedures created with CREATE PROCEDURE.

SQL Query:
SELECT
    n.nspname AS schema_name,
    p.proname AS procedure_name,
    l.lanname AS language,
    pg_get_userbyid(p.proowner) AS owner,
    pg_get_functiondef(p.oid) AS definition

        AND dep.objid = p.oid
        AND dep.deptype = 'e'
  )
ORDER BY n.nspname, p.proname;

INSIGHT #41: Locks
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_locks()
Headers     : PID, Lock Type, Mode, Granted, Relation, Transaction ID, Lock Category, Fast Path, User, Database
Description : Current locks held or awaited by PostgreSQL sessions, displaying default VirtualXID locks, system catalog relation locks, fastpath locks, and user table/transaction locks.

SQL Query:
SELECT
    l.pid,
    l.locktype,
    l.mode,
    l.granted::text AS granted,
    COALESCE(l.relation::regclass::text, 'N/A') AS relation,
    COALESCE(l.transactionid::text, 'N/A') AS transaction_id,
    CASE
        WHEN l.locktype = 'virtualxid' THEN 'VirtualXID (Default Session Lock)'
        WHEN l.locktype = 'transactionid' THEN 'TransactionID (Row/Txn Lock)'
        WHEN l.locktype = 'relation' AND n.nspname IN ('pg_catalog', 'information_schema') THEN 'System Relation (Catalog Lock)'
        WHEN l.locktype = 'relation' THEN 'User Relation (' || COALESCE(l.relation::regclass::text, 'OID ' || l.relation::text) || ')'
        ELSE INITCAP(l.locktype)
    END AS lock_category,
    l.fastpath::text AS fastpath,
    a.usename AS username,
    a.datname AS database_name
FROM pg_locks l
LEFT JOIN pg_class c ON c.oid = l.relation
LEFT JOIN pg_namespace n ON n.oid = c.relnamespace
LEFT JOIN pg_stat_activity a ON a.pid = l.pid
ORDER BY l.granted, l.pid, l.locktype;

INSIGHT #60: Stored code / object dependencies
--------------------------------------------------------------------------------
Method Name : PostgreSQLConnector.get_stored_code_dependencies()
Headers     : Schema, Object Name, Object Type, Referenced Object
Description : Dependency relationships for views, materialized views, functions and
              procedures using PostgreSQL dependency catalogs. The result is focused
              on stored-code/view objects and excludes system schemas.

SQL Query:
SELECT DISTINCT
    v_ns.nspname AS schema_name,
    v.relname AS object_name,
    CASE v.relkind
        WHEN 'v' THEN 'VIEW'
        WHEN 'm' THEN 'MATERIALIZED VIEW'
    END AS object_type,
    ref_ns.nspname || '.' || ref.relname AS referenced_object
FROM pg_class v
JOIN pg_namespace v_ns ON v_ns.oid = v.relnamespace
JOIN pg_rewrite r ON r.ev_class = v.oid
JOIN pg_depend d ON d.classid = 'pg_rewrite'::regclass AND d.objid = r.oid AND d.refclassid = 'pg_class'::regclass
JOIN pg_class ref ON ref.oid = d.refobjid
JOIN pg_namespace ref_ns ON ref_ns.oid = ref.relnamespace
WHERE v.relkind IN ('v', 'm')
  AND ref.oid <> v.oid
  AND v_ns.nspname NOT IN ('pg_catalog','information_schema')
  AND ref_ns.nspname NOT IN ('pg_catalog','information_schema')

UNION ALL

SELECT DISTINCT
    p_ns.nspname AS schema_name,
    p.proname AS object_name,
    CASE p.prokind
        WHEN 'f' THEN 'FUNCTION'
        WHEN 'p' THEN 'PROCEDURE'
        ELSE 'FUNCTION'
    END AS object_type,
    ref_ns.nspname || '.' || ref.relname AS referenced_object
FROM pg_proc p
JOIN pg_namespace p_ns ON p_ns.oid = p.pronamespace
JOIN pg_depend d ON d.classid = 'pg_proc'::regclass AND d.objid = p.oid AND d.refclassid = 'pg_class'::regclass
JOIN pg_class ref ON ref.oid = d.refobjid
JOIN pg_namespace ref_ns ON ref_ns.oid = ref.relnamespace
WHERE p.prokind IN ('f', 'p')
  AND p_ns.nspname NOT IN ('pg_catalog','information_schema')
  AND ref_ns.nspname NOT IN ('pg_catalog','information_schema')
ORDER BY schema_name, object_name, referenced_object;

NOTE:
For dependency rows involving objects not represented by pg_class/pg_proc,
additional pg_depend catalog decoding may be required. pg_depend is the
authoritative PostgreSQL dependency catalog.

================================================================================
SCHEMA FILTERING / CONNECTOR IMPLEMENTATION
================================================================================

For connector implementations that support:
  1. One selected schema
  2. Entire database

apply the schema predicate dynamically.

For pg_class / pg_namespace based queries:
    AND n.nspname = :schema_name

For information_schema queries:
    AND table_schema = :schema_name

For pg_stat_user_tables / pg_stat_all_indexes:
    AND schemaname = :schema_name

For pg_proc / pg_namespace based queries:
    AND n.nspname = :schema_name

When "Entire Database" is selected, omit the schema predicate.

Do NOT apply schema filtering to cluster/database-wide insights such as:
  - PostgreSQL version/environment
  - Database inventory
  - Users and roles
  - Server memory/configuration
  - WAL/archive configuration
  - Replication role
  - Physical/configuration file locations

For PostgreSQL extensions:
  - pg_stat_statements queries require pg_stat_statements.
  - cron.job queries require pg_cron.
  - pg_stat_checkpointer is used for current PostgreSQL checkpoint statistics.

Important:
  - Estimated row counts (reltuples/n_live_tup) are not exact counts.
  - Dead-tuple percentage is not exact physical bloat percentage.
  - Tablespace location queries do not provide filesystem total/used/free capacity.
  - Partition hierarchy queries using pg_inherits should be interpreted carefully because
    pg_inherits also represents table inheritance.
  - Duplicate-index candidates require review before dropping any index.
  - Archival/limited-usage candidates are recommendations only and depend on workload,
    retention policies and statistics-reset timing.
